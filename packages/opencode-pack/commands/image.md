Generate an image with omni-forge. Invoke the `forge_image` tool with a detailed prompt. Turns a short request into a rich prompt automatically.

## Usage
- `image a cyberpunk cat in the rain` → generates a 1:1 image
- `image 16:9 mountain valley at sunrise, photoreal` → aspect-aware

## Outcome
Returns the generated image URL served by the omni-forge core.
